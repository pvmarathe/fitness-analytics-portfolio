# Fitness Analytics Portfolio

A growing collection of data analytics projects built around fitness data, as I learn Python and work toward a career in data analytics engineering.

## About this project

This is Project #1 in the series: analyzing a simulated (dummy) dataset of daily workouts to practice core data analysis skills — cleaning data, exploring it with pandas, and visualizing trends with matplotlib.

## Tools used

- **Python** — the programming language
- **pandas** — for loading and analyzing tabular data
- **matplotlib** — for charts
- **Jupyter Notebook** — the environment used to write and run the analysis, step by step
